# Wpnz Sistemas

Landing page institucional da Wpnz Sistemas, com apresentação de soluções para food service, projetos publicados e integrações disponíveis.

## Desenvolvimento local

O site é estático. Sirva a pasta `dist` com qualquer servidor HTTP local.

## Publicação

O conteúdo publicado é a pasta `dist`. O domínio solicitado é `wr.wpn.com.br`.
